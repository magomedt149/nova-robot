# NOVA WORKFLOW — FREE LOCK

Это главный рабочий процесс проекта **NOVA**. Он нужен, чтобы ChatGPT/Work/Codex и человек всегда работали по одной схеме.

## 1. Главный принцип

**FREE LOCK:** не использовать Netlify credits, платные API, платные GPU, платные GitHub-ресурсы или внешние кредиты без явного разрешения владельца.

Репозиторий: `magomedt149/nova-robot`  
Основная ветка: `main`

---

## 2. Workflow разработки NOVA

1. Получить задачу.
2. Проверить текущее состояние репозитория и связанные файлы.
3. Сделать минимальное изменение без удаления уже работающих функций.
4. Проверить критические файлы и синтаксис.
5. Сохранить изменение в GitHub.
6. GitHub Actions автоматически запускает бесплатную проверку.
7. Если проверка успешна — статическая версия готовится для GitHub Pages.
8. Проверить опубликованную версию на iPhone.
9. Только после проверки считать задачу завершённой.

## 3. Что GitHub Actions делает автоматически

Файл автоматизации:

`.github/workflows/nova-free-pages.yml`

Он:
- запускается при изменениях в `main`;
- проверяет наличие основных файлов NOVA;
- проверяет JavaScript через `node --check`;
- собирает чистую папку `_site`;
- не использует Netlify;
- не использует платные API или GPU;
- публикует статический сайт через GitHub Pages, если Pages настроен на GitHub Actions.

## 4. Workflow видео / 3D

Для сложного видео NOVA использует отдельную производственную схему:

**идея → storyboard/shot plan → Blender previs → непрерывная camera path → blocking → timing/continuity → preview → AI/render engine → звук → FFmpeg → проверка → финальный MP4**

Правила:
- сначала фиксировать реальную непрерывную траекторию камеры;
- не подменять 3D-облёт последовательностью картинок;
- Blender/previs использовать перед финальным AI-render, когда важна геометрия движения;
- платный AI-render не запускать без разрешения;
- по умолчанию использовать локальные/бесплатные инструменты.

## 5. Где что находится

- **GitHub repository** — хранит код NOVA.
- **NOVA_WORKFLOW.md** — хранит наш общий порядок работы.
- **.github/workflows/** — автоматические GitHub Actions.
- **Codex** — пишет/исправляет код, когда он используется.
- **ChatGPT Work** — рабочее место, откуда можно управлять задачами.
- **Blender / local GPU / Colab fallback** — тяжёлый 3D/AI render; это не GitHub Pages.

## 6. Безопасное правило изменений

Перед изменением:
- не удалять рабочие функции без причины;
- не менять FREE LOCK;
- не запускать платные сервисы;
- не публиковать секреты/токены;
- не считать задачу выполненной, пока проверка не пройдена.
