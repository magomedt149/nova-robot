# NOVA 27 — Free AI Agent

NOVA — бесплатный браузерный ИИ-агент Тумсоева для iPhone, Android и компьютера.

## Что умеет

- голосовой чат на русском и английском;
- улучшенное распознавание речи: NOVA выбирает более подходящий вариант из нескольких распознанных фраз и исправляет частые ошибки;
- обучаемые голосовые исправления: можно сказать «когда слышишь X, понимай как Y», и правило сохранится на устройстве;
- надёжное пробуждение фразой «Привет, Нова» и распознавание вариантов «Ново», «Новая», «На́ва» и других частых ошибок;
- персональные правила общения: NOVA запоминает, как пользователю удобнее получать ответы;
- защита от повторов: NOVA помнит недавний запрос и старается не заставлять пользователя повторять одно и то же;
- проверка актуальности: для быстро меняющихся тем NOVA не выдаёт старую информацию за свежую и открывает живой веб-поиск;
- режим «Учим английский»: 10 слов и фраз в день, русская транскрипция, произношение и голосовая проверка;
- локальная память, заметки, задачи и таймеры;
- бесплатный локальный AI через WebLLM и WebGPU;
- перевод, погода, Wikipedia, карты и поиск;
- компас, анимации NOVA, Тумсоева и лунной кошки;
- Motion + VFX Studio: бесплатные локальные camera moves и эффекты дождя, дыма, тумана, искр, молнии, огня, обломков и взрыва;
- NOVA Auto Director: из описания сцены автоматически создаёт shot plan, 3D blocking, объектив, camera path, continuity lock и финальный AI prompt; платные вызовы по умолчанию отключены;
- установка на главный экран как PWA.

## NOVA Auto Director / Blender

В Motion + VFX Studio кнопка «Собрать сцену автоматически» сначала делает бесплатный режиссёрский план и continuity-проверку. Из браузера можно скачать:
- `NOVA_scene_pack.json`;
- `NOVA_blender_blocking.py`;
- финальный AI prompt после одобрения preview.

Для локального компьютера есть zero-credit runner:

```bash
python3 automation/nova_pipeline.py --prompt "two people in a room, 5 sec, orbit camera, rain" --run-blender
```

Он не использует сеть и платные API. Если Blender установлен, NOVA создаёт headless blocking scene + preview MP4. Только после одобрения preview имеет смысл вручную отправлять финальный prompt в Seedance/Higgsfield/другую внешнюю модель.

## Правила поведения NOVA 27

По умолчанию NOVA старается отвечать по-русски, сначала давать прямой практичный ответ, не задавать повторные вопросы, самостоятельно использовать доступные инструменты и отдельно проверять свежесть данных, которые могли измениться.

## Публикация на Netlify

1. Подключите этот GitHub-репозиторий в Netlify.
2. Build command оставьте пустой.
3. Publish directory укажите `.`.
4. Нажмите Deploy.

Секретные ключи и платный API для основной версии не нужны. Локальная модель загружается в браузер только после нажатия кнопки мозга; для неё нужен браузер с WebGPU и интернет при первой загрузке.

Подробная инструкция находится в [README.txt](./README.txt).
