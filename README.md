# NOVA 27 — Free AI Agent

NOVA — бесплатный браузерный ИИ-агент Тумсоева для iPhone, Android и компьютера.

## Что умеет

- голосовой чат на русском и английском;
- улучшенное распознавание речи: NOVA выбирает более подходящий вариант из нескольких распознанных фраз и исправляет частые ошибки;
- обучаемые голосовые исправления: можно сказать «когда слышишь X, понимай как Y», и правило сохранится на устройстве;
- надёжное пробуждение фразой «Привет, Нова» и распознавание вариантов «Ново», «Новая», «На́ва» и других частых ошибок;
- персональные правила общения: NOVA запоминает, как пользователю удобнее получать ответы;
- защита от повторов: NOVA помнит недавний запрос и старается не заставлять пользователя повторять одно и то же;
- проверка актуальности: для быстро меняющихся тем NOVA не выдаёт старую информацию за свежую и открывает живой веб-поиск;
- режим «Учим английский»: 10 слов и фраз в день, русская транскрипция, произношение и голосовая проверка;
- локальная память, заметки, задачи и таймеры;
- бесплатный локальный AI через WebLLM и WebGPU;
- перевод, погода, Wikipedia, карты и поиск;
- компас, анимации NOVA, Тумсоева и лунной кошки;
- Motion + VFX Studio: бесплатные локальные camera moves и эффекты дождя, дыма, тумана, искр, молнии, огня, обломков и взрыва;
- NOVA Auto Director: из описания сцены автоматически создаёт shot plan, 3D blocking, объектив, camera path, continuity lock и финальный AI prompt; платные вызовы по умолчанию отключены;
- Remote GPU / Google Colab: умная кнопка **GPU Render** в NOVA открывает/возобновляет удалённый рендер, Motion Studio делает preflight, умеет выполнить 1-секундный Blender self-test, отправляет исходник по частям и возвращает готовый MP4 на телефон;
- установка на главный экран как PWA.

## Remote GPU / Google Colab

### NOVA VIDEO AUTO — САМЫЙ ПРОСТОЙ РЕЖИМ

### БЕЗ COLAB ПО УМОЛЧАНИЮ

Обычный сценарий Video Auto больше не зависит от Google Colab. Команда **«сделай видео…»** открывает локальный режим и запускает рендер прямо на iPhone через Canvas + MediaRecorder. Если выбран исходный ролик, NOVA использует его как фон/видеослой, накладывает Motion/VFX/текст и по возможности сохраняет исходный звук через Web Audio. Никакого `Run all`, Connect Code или GPU-подключения для этого режима нет.

Самый простой запуск теперь такой:

```
«Нова, сделай видео 5 секунд, дождь, push-in»
→ NOVA Video Auto
→ «✨ СДЕЛАТЬ ВИДЕО»
→ готовый MP4/WEBM на iPhone
```

Для задач, где действительно нужно генеративное text-to-video / image-to-video / замена персонажа, локальный браузер не подменяет AI-модель. В таком случае Video Auto не открывает Colab автоматически: пользователь может один раз подключить **постоянный NOVA GPU Worker** (домашний компьютер или постоянный GPU-сервер), который стартует сам и дальше не требует `Run all`. Старый Colab оставлен только как ручной резервный fallback в дополнительных настройках.

В обычной работе технические слова GPU/Token/Worker пользователю не нужны. Главная кнопка NOVA теперь называется **«Сделать видео»**, а фразы вроде **«сделай видео…»**, **«создай видео…»**, **«сгенерируй видео…»** автоматически открывают Video Auto и переносят описание сцены в prompt.

Motion Studio по умолчанию открывается в простом интерфейсе: описание сцены + необязательный исходный видеофайл + одна кнопка **«✨ СДЕЛАТЬ ВИДЕО»**. Ручные VFX/камера/движок/URL/Token спрятаны и доступны только через дополнительные настройки.

В обычном сценарии Colab больше не открывается. Старый Colab notebook оставлен только как резервный ручной fallback в дополнительных настройках. Последняя кнопка копирует Connect Code и пытается закрыть вкладку; если браузер не даёт закрыть её, выполняется возврат назад. После возврата Motion Studio пытается прочитать Connect Code из буфера и продолжить автоматически; если iOS требует жест пользователя для clipboard, достаточно снова нажать ту же большую кнопку.

### FULL AUTO GPU

### ПРОСТОЙ РЕЖИМ — ОДНА КНОПКА

В Motion Studio основной интерфейс Remote GPU теперь свёрнут до кнопки **«✨ СДЕЛАТЬ ВИДЕО»**. Пользователь описывает сцену и, если нужно, выбирает исходное видео. Дальше NOVA сама: включает Full Auto + Auto Recovery, проверяет сохранённый worker, пытается прочитать свежий Connect Code из буфера, восстанавливает незавершённый job или открывает Colab только если живой runtime действительно отсутствует.

Если Colab пришлось открыть заново, перед переходом NOVA заранее сохраняет job и доступный исходник в recovery-cache. После **Run all → Copy NOVA CONNECT CODE** достаточно вернуться в Motion Studio: при разрешённом clipboard access NOVA сама считывает новый код, подключается и продолжает рендер. Если iOS не разрешает чтение буфера без жеста, остаётся одно нажатие кнопки вставки в дополнительных настройках.

Технические URL, Token, выбор движка и ручные кнопки теперь спрятаны в блок **«Дополнительные настройки»** и в обычной работе не нужны.

### AUTO RECOVERY

Remote GPU теперь сохраняет recovery-state в браузере и, если размер позволяет, сам исходный видеофайл в IndexedDB iPhone. Worker также сохраняет количество принятых upload-частей, поэтому после перезагрузки страницы или краткого обрыва NOVA может продолжить upload с последней подтверждённой части, а не начинать весь файл заново. При кратком сетевом обрыве NOVA использует экспоненциальные повторные проверки и продолжает текущий job, если старая Colab-сессия возвращается. Worker публикует уникальный `session_id`, поэтому новая Colab-сессия определяется автоматически.

Если старая сессия действительно уничтожена Google, NOVA не теряет параметры render job: после появления нового worker она сначала пытается восстановить checkpoint из Google Drive (когда Drive уже был смонтирован), а затем автоматически пересоздаёт job и повторно отправляет сохранённый локальный исходник. Для файлов до примерно 1.5 GB включён best-effort локальный recovery cache с проверкой реально доступной квоты iPhone; для более крупных файлов job/settings сохраняются, но после полного уничтожения Colab и перезапуска страницы может потребоваться один раз снова выбрать тот же исходный файл.

Пока сама Colab runtime остаётся живой, notebook-watchdog автоматически перезапускает сам NOVA worker на том же порту, если процесс упал; Cloudflare tunnel при этом продолжает использовать прежнее подключение. Когда пользователь возвращается из Colab, NOVA также пытается прочитать новый `NOVA CONNECT CODE` из буфера обмена, если браузер уже разрешает clipboard access. Если iOS требует жест пользователя, остаётся одно нажатие **«Вставить код из буфера и подключить»**.

Команда или кнопка **GPU Render** переводит Motion Studio в режим `FULL AUTO`. NOVA переносит текст команды в prompt, проверяет сохранённый worker, выбирает движок и при готовом Colab сразу создаёт Preview. Если включён Full Auto Final, завершённый preview повышается до нового Final job на стороне worker **без повторной загрузки исходного видео**; Final по умолчанию рендерится в 30 FPS. Final job использует сохранённый source/Scene Pack, а готовый MP4 возвращается на iPhone по временной download-ticket ссылке.

Если Colab runtime уже жив, после команды пользователя дополнительных действий не нужно. Если Google завершил бесплатный runtime, NOVA сама обнаруживает обрыв, сохраняет recovery-state и продолжает попытки. Но сайт по-прежнему не может программно выдать себе новый бесплатный Google GPU или обойти Google authorization. После запуска новой runtime-сессии и получения нового Connect Code pipeline восстанавливается автоматически настолько, насколько сохранён исходник/checkpoint.

Открой в Motion + VFX Studio блок **Remote GPU / Google Colab**, затем ноутбук:

`blender-colab/NOVA_Remote_GPU_Worker.ipynb`

Ноутбук устанавливает Blender/FFmpeg/WanGP, запускает защищённый токеном NOVA worker и бесплатный Cloudflare Quick Tunnel. В конце он показывает кнопку **Copy NOVA CONNECT CODE**. В Motion Studio есть кнопка **«Вставить код из буфера и подключить»**, поэтому подключение на iPhone занимает два нажатия без ручного копирования URL/Token.

Поток работы:

```
NOVA on iPhone → chunked HTTPS upload → Colab GPU → Blender / FFmpeg / WanGP Python API → MP4 → NOVA
```

- Blender, FFmpeg и WanGP jobs выполняются автоматически без ручной Gradio-генерации.
- WanGP подключён через официальный in-process Python API из `shared/api.py`; в интерфейсе и документации явно указано, что используется WanGP.
- На бесплатной T4 NOVA отдаёт приоритет облегчённым video-моделям (FastWan), генерирует экономно и только затем делает iPhone-совместимый H.264.
- Если у модели нет video-input, NOVA автоматически извлекает первый кадр и использует image-to-video вместо падения с ошибкой.
- Preview по умолчанию облегчённый; Final — 1080p H.264 после проверки preview.
- Большие исходники передаются частями по 8 MB с автоматическими повторами при кратком обрыве сети.
- При включённом Drive mirror completed job копируется в `MyDrive/NOVA_RENDER_QUEUE/completed/`.
- WanGP model/settings для каждого задания сохраняются в `WANGP_SETTINGS.json`, а прогресс и отмена передаются обратно в Motion Studio.
- Готовый MP4 открывается по временной download-ticket ссылке: секретный worker Token не попадает в URL, а iPhone не обязан сначала держать весь MP4 в памяти как Blob.
- Пока идёт upload/render, Motion Studio по возможности удерживает экран iPhone активным через Screen Wake Lock.
- Протокол worker имеет версию и capability flags: Motion Studio определяет устаревшую Colab-сессию до отправки большого видео.
- Кнопка **«Запустить Remote GPU»** возобновляет активный job, проверяет сохранённое подключение либо открывает актуальный Colab notebook. Кнопка **«Тест рендера 1 сек»** проверяет весь путь NOVA → worker → Blender → MP4 без тяжёлой WanGP-генерации.
- Auto engine учитывает задачу и наличие исходного видео: WanGP для новой AI-генерации, Blender для VFX/3D/tracking, FFmpeg для encode/upscale. Перед запуском выполняется preflight и безопасный fallback, когда это возможно.
- URL и Token действуют только пока живёт Colab runtime. После перезапуска Colab подключение нужно вставить заново.

## NOVA Auto Director / Blender

В Motion + VFX Studio кнопка «Собрать сцену автоматически» сначала делает бесплатный режиссёрский план и continuity-проверку. Из браузера можно скачать:
- `NOVA_scene_pack.json`;
- `NOVA_blender_blocking.py`;
- финальный AI prompt после одобрения preview.

Для локального компьютера есть zero-credit runner:

```bash
python3 automation/nova_pipeline.py --prompt "two people in a room, 5 sec, orbit camera, rain" --run-blender
```

Он не использует сеть и платные API. Если Blender установлен, NOVA создаёт headless blocking scene + preview MP4. Только после одобрения preview имеет смысл вручную отправлять финальный prompt в Seedance/Higgsfield/другую внешнюю модель.

## Правила поведения NOVA 27

По умолчанию NOVA старается отвечать по-русски, сначала давать прямой практичный ответ, не задавать повторные вопросы, самостоятельно использовать доступные инструменты и отдельно проверять свежесть данных, которые могли измениться.

## Публикация на Netlify

1. Подключите этот GitHub-репозиторий в Netlify.
2. Build command оставьте пустой.
3. Publish directory укажите `.`.
4. Нажмите Deploy.

Секретные ключи и платный API для основной версии не нужны. Локальная модель загружается в браузер только после нажатия кнопки мозга; для неё нужен браузер с WebGPU и интернет при первой загрузке.

Подробная инструкция находится в [README.txt](./README.txt).
