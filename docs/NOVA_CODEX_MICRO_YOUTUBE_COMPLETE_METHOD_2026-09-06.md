## 1. Исходная задача
Сделать русский объясняющий Short по теме Codex Micro, сохранить понятный видеоряд, заменить плохую роботизированную озвучку на бесплатную NOVA «Ирина» и опубликовать на YouTube.

## 2. Постоянный бесплатный TTS NOVA
- Engine: Piper
- Voice: ru_RU-irina-medium
- Locale: ru-RU
- Pitch: 1.0
- Formants: 1.0
- eSpeak запрещён
- Автоматическая подмена голоса запрещена
- Платные TTS/API/кредиты без прямого разрешения пользователя запрещены
- Для каждого нового текста генерировать свежую полную дорожку

### Порядок
1. Сначала локальный/браузерный Piper Irina.
2. Если локально недоступно — бесплатный GitHub Actions workflow:
   .github/workflows/nova-irina-tts.yml
3. Использовать официальную модель Piper ru_RU-irina-medium.
4. Синтезировать новый WAV.
5. FFmpeg: заменить старую аудиодорожку, видеоряд не менять.
6. При необходимости подогнать длительность без изменения тембра/высоты тона.
7. Проверить разборчивость русского, отсутствие старого голоса и повторов.
8. Выдать один финальный MP4.

Основной эталон также хранится в:
