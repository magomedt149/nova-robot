# TUMSOEV — постоянный метод «добавь и допиши»

Дата фиксации: 2026-09-08

## Команда
Когда пользователь говорит **«добавь и допиши»**, применять этот метод по умолчанию.

## Постоянный метод
1. Сначала проверить существующие запланированные задачи и сохранённые методы.
2. Если новая просьба относится к уже существующей задаче — **не создавать дубликат**, а дописать новые правила в существующую задачу.
3. Если новая просьба действительно отдельная по смыслу — создать отдельную задачу.
4. Если достигнут лимит активных задач:
   - сначала найти явный дубликат или задачу, уже полностью покрытую другой;
   - такой дубликат можно поставить на паузу, чтобы освободить место;
   - важные уникальные задачи не отключать и не удалять без отдельного разрешения;
   - после этого сохранить новую или дополненную задачу.
5. Не менять расписание, смысл и важные ограничения существующей задачи без необходимости.
6. Для мониторинга использовать условные уведомления: если всё нормально — не беспокоить; сообщать только о важном изменении, найденной проблеме, исправлении или когда требуется решение пользователя.
7. После команды «добавь и допиши» результат должен быть **реально сохранён**, а не только описан в ответе.

## Для NOVA
- Проверять текущий `main` и последние GitHub Actions.
- При ошибке сначала читать логи и исправлять реальную причину минимальным безопасным изменением.
- После исправления подтверждать свежий успешный `Validate NOVA`.
- Не ослаблять проверки ради зелёного CI.
- Соблюдать NOVA FREE LOCK: никаких платных API, кредитов, платных рендеров или платного compute без отдельного прямого разрешения пользователя.

## Короткая формула
**«ДОБАВЬ И ДОПИШИ» = найди подходящее существующее → дополни → не дублируй → при лимите освободи место только за счёт явного дубля → сохрани → проверь результат.**
