# NOVA — постоянный бесплатный метод русской озвучки «Ирина»

Статус: ПОСТОЯННЫЙ СТАНДАРТ. Не менять без прямой команды пользователя.

## Голос
- Provider: Piper.
- Voice ID: `ru_RU-irina-medium`.
- Locale: `ru-RU`.
- Pitch: 1.0.
- Formants: 1.0.
- Запрещена автоматическая подмена голоса.
- Запрещён eSpeak и любой технический/роботизированный TTS вместо Ирины.
- Для каждого нового текста синтезировать свежую полную дорожку. Не переиспользовать старые demo WAV/MP3.

## Бесплатный порядок
1. Сначала использовать локальный/браузерный Piper Irina в NOVA.
2. Если точная Irina недоступна в текущей рабочей среде — использовать бесплатный GitHub Actions рендер с официальной моделью Piper `ru_RU-irina-medium`.
3. После синтеза заменить старую/исходную аудиодорожку в MP4 через FFmpeg, сохранив видеоряд.
4. Подогнать длительность без изменения высоты тона/тембра.
5. Проверить разборчивость русского, совпадение текста и отсутствие повторов старого аудио.
6. Выдать один готовый MP4.

## Деньги
- Платные TTS/API/кредиты по умолчанию запрещены.
- Higgsfield, HeyGen, Runway и любые платные генерации не запускать для этой задачи без отдельного прямого разрешения пользователя.
- Если бесплатность не подтверждена — считать действие потенциально платным и не запускать.

## Технический резерв
В репозитории используется workflow:
`.github/workflows/nova-irina-tts.yml`

Он скачивает Piper и официальную модель `ru_RU-irina-medium`, генерирует WAV и отдаёт его как artifact для дальнейшего FFmpeg-микса.

## Постоянное правило
Новый русский explainer/урок/пересказ → точный новый текст → pronunciation normalization → свежая Piper Irina → FFmpeg/Remotion → проверка → один финальный MP4.

Этот стандарт имеет приоритет над временными TTS-настройками и не должен заменяться eSpeak или платным TTS автоматически.
