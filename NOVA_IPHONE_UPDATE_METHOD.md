# Nova Super App — обновление и 3D на iPhone

Контрольная версия: **27.31.3**. Версия в репозитории не доказывает,
что эта версия уже опубликована на сайте.

## Обновление PWA

1. Проверь `version.json` на том же сайте, где открываешь NOVA.
2. Если сайт уже показывает 27.31.3, закрой и открой PWA. При необходимости
   открой `update.html` на этом же сайте: он обновляет кэш NOVA, сохраняя
   localStorage, IndexedDB, память и настройки.
3. Проверь v27.31.3 на главном экране, затем VIDEO STUDIO → 3D.
4. Если `version.json` старый или даёт 404, очистка iPhone не поможет:
   новая версия ещё не опубликована. Не удаляй приложение и данные сайта.

Production: https://dashing-otter-990b47.netlify.app/

FREE LOCK: в текущем `netlify.toml` обычные коммиты, branch deploy и deploy
preview пропускаются. Production release требует отдельного изменения
`.netlify-release` существующим release workflow. Не запускать его автоматически
при ремонте. Репозиторий GitHub и опубликованный сайт проверяются отдельно.

## Настоящая модель: вращение и камера

В блоке **«Моя 3D-модель · iPhone»** выбери свой файл:

- **GLB**: вращай одним пальцем, приближай двумя. «Сбросить ракурс» возвращает
  начальный вид. На поддерживаемом iPhone доступна кнопка «Показать в комнате».
- **USDZ**: нажми «Открыть USDZ в комнате» для AR Quick Look. Если установленная
  PWA или встроенный браузер не открывает AR, используй Safari или открой
  сохранённый USDZ в приложении «Файлы».
- Файлы остаются на устройстве; лимит 50 МБ. GLB должен содержать геометрию
  и текстуры внутри файла, без Draco/Meshopt/KTX2 и внешних ссылок. Просмотрщик
  включён в репозиторий, CDN и платные API не используются.
- Фото, MP4 и CSS blockout не заменяют 3D-модель. В репозитории нет готовых
  моделей мечети или волка: для них нужен соответствующий GLB/USDZ.

«Записать наклоны iPhone» — отдельная запись датчика движения для Scene Pack.
Это не запись видео и не AR. Нужны HTTPS, разрешение движения и активная вкладка.
Отказ в разрешении, отсутствие данных или сворачивание страницы должны
корректно останавливать запись.

## Blender Agent на компьютере

Просмотр GLB/USDZ работает без Agent. Для SCAN/DIAG/рендера нужна запущенная
Blender-сессия с установленным bridge и gateway на компьютере.

`127.0.0.1` на iPhone указывает на телефон. Укажи адрес компьютера и token.
Для HTTPS-страницы NOVA используй gateway с сертификатом, которому доверяет
 iPhone и который выдан на используемое имя/IP:

```sh
python blender-agent/nova_blender_http_gateway.py --host 0.0.0.0 --allow-lan --token YOUR_LAN_TOKEN --tls-cert /path/to/cert.pem --tls-key /path/to/key.pem
```

Укажи `https://ИМЯ_КОМПЬЮТЕРА:9877` и тот же token. Оба устройства должны
видеть друг друга в локальной сети. Самоподписанный недоверенный сертификат
не решает блокировку Safari; сертификат и доверие настраиваются на устройствах.
Не открывай gateway в Интернет. Диагностика не устанавливает bridge и не
обходит сетевые ограничения браузера.

## Проверки перед признанием исправления завершённым

1. Safari и PWA: GLB загружается, пальцы вращают/масштабируют, закрытие
   освобождает модель; USDZ/GLB открываются в AR на физическом iPhone.
2. Запрет движения и пустые данные не дают ложного сообщения об успехе.
3. DIAG показывает результаты сцены и FLOW/LOOP, а не только зелёный статус.
4. Пятикадровый 1 fps тест служит проверкой света/поз; повтор кадров до 24 fps
   не делает его плавным. Ручной режим 12 fps предназначен для оценки движения.
5. GitHub рендер запускается только вручную. Обновление кода не запускает его.
